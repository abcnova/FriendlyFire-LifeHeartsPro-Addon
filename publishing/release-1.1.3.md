# FriendlyFire LHP Addon 1.1.3

This update improves the LifeHeartsPro integration, removes a full LifeHeartsPro gameplay reload from startup synchronization, and enables configurable update checks by default. It also adds admin notices with direct Modrinth and GitHub links, cleans up temporary feedback data when players leave, and verifies one JAR against the published Paper API lines from 1.21 through 26.3.

LifeHeartsPro is required. Install or update LifeHeartsPro before using this add-on.
