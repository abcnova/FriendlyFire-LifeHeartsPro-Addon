# FriendlyFire (LifeHeartsPro Addon)

FriendlyFire LHP Addon adds per-team friendly-fire controls to LifeHeartsPro. It protects teammates from melee, projectiles, tridents, potions, area-effect clouds and optional tamed-wolf attacks.

**Required:** LifeHeartsPro. Install and enable LifeHeartsPro before FriendlyFire LHP Addon.

## Features

- Set friendly fire separately for each LifeHeartsPro team.
- Configure attacker and victim messages, action bars, sounds, cooldowns and bypass permissions.
- Manage settings with `/friendlyfire team <team> <on|off>` and `/friendlyfire info <team>`.
- English, German, French and Spanish messages.
- Optional background Modrinth update checks with notices for operators and admins.

## Compatibility

One Java 21 bytecode JAR targets the Bukkit API shared by Paper and Spigot, from Minecraft 1.21 through 26.3. Paper 1.21.x requires Java 21; Paper 26.1+ requires Java 25.
